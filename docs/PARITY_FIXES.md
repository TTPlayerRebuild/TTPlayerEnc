# 原版行为对照修复（2026-10-06）

本次按原版 `ttp_enc.dll` 的伪代码、资源和机器指令修复适配层，保留 LAME 4.0 与 mp3PRO 免安装注册表支持。原版 DLL 的 SHA-256 为 `c0f116ea6c27f4a5f5836ca1a425642f5cb301ed47f0f24f2dbad9016556b8ff`。

## MP3 编码参数

依据 `60251765`，恢复显式设置输出采样率、ABR 比特率预设、Copyright/Original/CRC/Private 标志。CBR 不启用 Xing/Info，ABR/VBR 继续启用。重复启动正在编码的 MP3 会话按原版返回成功。

成对测试验证：48 kHz 输入、ABR 96 Kbps 的输出恢复为 48 kHz；默认 CBR 恢复 192 Kbps；CBR 帧标志与原版一致。原版显示资源中的 LAME 3.90.3 与内核版本函数返回的 LAME3.93 不一致。本项目继续使用官方 LAME 4.0，压缩结果不要求与旧内核逐字节相同。

## WMA 参数与标签

按 `60254722` 匹配采样率、声道、质量或比特率，取消按距离选择近似格式。比特率匹配采用原版的 `(nAvgBytesPerSec * 8 + 56) / 1000` 规则。没有对应格式时返回 `E_INVALIDARG`，不偷偷更改采样率或比特率。恢复创建 `WMT_VER_7_0` 配置；实际编码器仍由系统提供。

XP、Win7 的系统编码器均不支持本次测试的 48 kHz／质量 75 组合；原版 DLL 同样返回 `80070057`。44.1 kHz／质量 75 在两台虚拟机中均成功。参数是否可用由该系统实际枚举的格式决定。

补齐 `6025515B` 的标准字段映射：

| 输入 | 写入属性 |
| --- | --- |
| Composer | WM/Composer |
| Lyrics | WM/Lyrics |
| ISRC | WM/ISRC |
| Subtitle | WM/SubTitle |
| Copyright_URL | CopyrightURL |

其余原有 Title、Artist、Album、AlbumArtist、Date、Genre、Tracknumber、Comment、Copyright、Rating、四项 ReplayGain 字段继续对应原版；保留 Year/Track 别名及自定义文本扩展。Windows Media SDK 将 CopyrightURL 存入 ASF 的 Content Branding Object，并非普通扩展文本属性，因此 FFprobe 的标签列表不展示该字段；已检查实际文件中的 URL 数据。

## 宿主标签接口与真实转换

MP3/mp3PRO 优先使用宿主 `ttpctrl.dll` 或 EXE 导出的 `CreateStdContent`，由宿主决定标签格式。mp3PRO 重新打开输出文件时也使用 `CreateStreamOnFile`，恢复 `6025252F` 的调用路径。没有宿主接口时保留独立 ID3v2.3 写入；回退写入同时补齐 USLT、TSRC、TIT3 和 WCOP。

原版文件流直接写文件，但 `Commit` 返回未实现。以前将这个结果当作编码失败，导致完成音频后没有进入标签写入。现在容许 `E_NOTIMPL`／`STG_E_INVALIDFUNCTION`，其他磁盘与提交错误仍会返回给宿主。

真实原版 TTPlayer.exe 已验证：新插件枚举、MP3/WMA 配置入口、三类编码器输出、两首文件批量转换、输出解码以及标签回读。切换原版的 `MP3WriteTagType` 后，MP3 分别生成 ID3v2 和 ID3v1＋APEv2；mp3PRO 也通过原版默认标签策略验证。

## 有意保留的差异

- LAME 4.0 的算法，以及新增的编码模式。
- 更多 PCM 输入格式、独立转换缓冲区、不修改宿主输入、非有限浮点值处理。公共编码输入仍转换为 16 位；无损模式不保留高位深源文件的全部精度。
- 可靠的编码尾部刷新、VBR 信息帧回写和错误传播；不复刻原版空 Finish 的细节。
- 配置确定后立即保存、目录不可写时回退到用户配置目录。
- mp3PRO 同目录发现、Unicode 路径、缺省预设和声道适配、单会话保护及滤镜导入指针恢复。
- 元数据可预先缓存在重建接口内，完成音频后交由宿主写入；接口可用时机及部分异常 HRESULT 不宣称逐项相同。

## VBR 分组与合并选项后的回归

本地、XP 和 Win7 各通过 19 项窗口操作检查，包含直接选择新增模式、模式切换、取消、保存及重新打开。已移除“扩展…”按钮和对应资源。MP3 的两组 VBR 均使用原有 `Quality/Mode=2`，通过 `Quality/Preset` 的 1000–1007／1100–1109 恢复所属分组。切换两个 VBR 分组及 CBR/ABR 保留当前窗口内各下拉框选择。编码内核及配置键未改变。

WMA 质量 VBR 仍为 10、25、50、75、90、98 六档。当前 Windows 11 在 44.1 kHz／双声道下，手动配置质量 98 编码成功，质量 100 无匹配格式并返回 E_INVALIDARG；质量数字不表示保留数据的百分比。无损继续使用独立的 16 位无损模式。
